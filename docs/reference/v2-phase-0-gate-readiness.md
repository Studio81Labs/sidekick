## Evidence limits

- Tooling, synthetic cases and bounded source fixtures are not representative
  accuracy evidence; all count/rate/composition/fingerprint gates and independent
  source/label review are required together.
- The review profile explicitly permits unknown origin. It does not claim
  positive reconnect/voluntariness support or retroactively rename old reports.
- An unsigned archive plus checksum proves integrity only. The controlled pilot
  is not a public authenticated installer/update channel or cross-platform claim.
- A safe worker reload is not application-file update evidence. A same-bundle
  restart is not proof of a two-version update.
- This review product makes no automatic EV, mistake, mastery or learning claim.
